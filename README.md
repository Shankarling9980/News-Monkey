# News Monkey

News Monkey is a React.js based news application that displays the latest news from different categories using News API.

---

## 🚀 Features

- Latest news updates
- Category-wise news
- Infinite scrolling
- Responsive user interface
- Fast loading news articles

---

## 🛠️ Technologies Used

- React.js
- JavaScript
- Bootstrap
- HTML
- CSS
- News API

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/News-Monkey.git
```

Go to project directory:

```bash
cd News-Monkey
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm start
```
